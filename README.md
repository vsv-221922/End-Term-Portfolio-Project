## ✨ Features

| Feature | Description |
|---|---|
| 🎬 **Video Background** | Full-screen looping video creates an immersive racing atmosphere |
| 🎵 **Background Music** | Toggle-able background audio with a sleek floating music button |
| 📜 **Scroll-Snap Sections** | Smooth full-page scroll-snapping for a presentation-like experience |
| 📱 **Fully Responsive** | Adaptive layout for desktop, tablet, and mobile screens |
| 🏁 **Racing Theme** | Custom CSS variables with a bold red, black & gold color palette |
| 🃏 **Animated Cards** | Hover-animated skill and contact cards with gradient borders |
| ♿ **Accessible** | Semantic HTML, alt text, focus states, and proper link protocols |

- **HTML5** — Semantic markup, `<video>`, `<audio>` elements

- **Vanilla JavaScript** — Audio toggle functionality (inline)

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)

### Run Locally

```bash
# Clone the repository
git clone https://github.com/vsv-221922/End-Term-Portfolio-Project.git

# Navigate into the project
cd End-Term-Portfolio-Project

# Open in your default browser
# On Windows:
start index.html
# On macOS:
open index.html
# On Linux:
xdg-open index.html
```

Or simply **double-click** `index.html` to open it.

## 🎨 Sections Overview

### 1. 🏠 Hero
A bold, gradient-text title — *"Srinu's Universe"* — with a tagline about technology, creativity, and innovation.

### 2. 👤 Profile
A profile photo with a gradient border frame alongside a personal info card displaying name, DOB, age, and university details.

### 3. ⚡ Skills & Interests
A two-column grid of cards highlighting technical skills (editing, taekwondo, dance) and personal interests (nature, tech research, exploration).

### 4. 🔗 Connect
Clickable contact cards for Email, LinkedIn, GitHub, and more — each with hover animations and accent borders.

### 5. 🏁 Footer
A clean, centered copyright bar with a red top-border accent.
